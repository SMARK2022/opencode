## Source intent
Windows CI 上 `bun turbo test:ci` 并行运行 `core:test:ci` 与 `opencode:test:ci` 时，
`core:test:ci` 的输出被缓冲且进程不退出，导致 75 分钟超时被取消。补丁给 turbo
加入 `--concurrency=1` 强制串行执行：
- 消除并行资源竞争（内存、CPU、turbo 长时间存活进程），使被缓冲输出能随进程
  结束刷新。
- 预期总时长从"超时取消"变为 ~30 分钟（opencode 24m + 其余 <2m + 安装 4m）。
- 改动只影响 `.github/workflows/test.yml` 中 "Run upstream unit compatibility
  tests" 步骤的 run 行：`bun turbo test:ci --continue=always --summarize`
  → `bun turbo test:ci --continue=always --summarize --concurrency=1`，并新增
  3 行中文注释说明超时根因与串行取舍。
