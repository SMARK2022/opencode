### h-D 重写逐点说明

- readiness：`awaitWithTimeout(Effect.gen(function*(){ yield* llm.wait(1); return yield* Effect.promise(() => retry.promise) }), "first-progress retry was not published", "20 seconds")`——已发布信号（fixture 首请求到达 + retry promise）替代计时断言，包级 20s 仅防挂死；
- `Fiber.join(fiber)` 与 gate 释放移至边界之后执行：gate 由 addFinalizer 兜底，任何提前失败路径不会挂起后续 provider 请求；
- `const parts = yield* MessageV2.parts(msg.id)`——目标 MessageV2.parts 为 Effect 形态；
- 断言保留：attempt=1、"SSE read timed out"（真实 progress producer）、result==="continue"；新增 "after" 文本终态断言替代 `llm.calls===2`——repeat 契约下次数不再是合同，源该断言的意图（失败请求与重试请求都真实到达 fixture）由 wait(1)+join+终态文本联合承载；
- `chunkTimeout: 25`→`500`：25ms 在 CI 调度抖动下误触发首块超时；500ms 保持"闸门永远晚于 deadline"的核心语义且消除环境噪声（目标值与源意图一致：稳定可重复的红/绿判定）。
