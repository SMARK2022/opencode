## 3. SMARK Intent
- 用户可见行为：所有工具（read/edit/write/shell/apply_patch/generic）统一渲染 auto-review 状态行；点击审查行打开 reviewer 子会话不触发父工具卡片折叠/展开。
- 受保护不变量：reviewID 从父工具到子会话 transcript 完整 mirror——一个 reviewer 子会话可累积多次审查轮次，每次需带父 autoReview.reviewID。
- 正常路径：ToolPart → ToolAutoReview.Provider → InlineTool/BlockTool → ToolAutoReviewLine → AutoReviewLine。
- 边界路径：无 autoReview metadata → ToolAutoReviewLine 不渲染；apply_patch 内部 BlockTool autoReview={false} → 外层统一渲染。
- 并发/重试路径：reviewer stream 瞬时 provider 故障 → SessionRetry.retry() 重试 → 父工具 autoReview 保持 reviewing 直到最终结果。
