## 3. SMARK Intent
- 用户可见行为：cancel 在 auto-review 进行中触发时，shell 工具终态化为 error 且携带 aborted 审查状态（而非残留 reviewing）；reviewer 子会话的 assistant 被终态化，permission_review_decision 不在 cancel 后完成。
- 受保护不变量：中止路径的 error 文案和 metadata 必须跨 processor/prompt/tools 三处一致；autoReview 信封在中止时保留并标记 aborted 状态。
- 正常路径：工具正常完成 → completion 路径不动；非中止错误 → 保留原始错误原因和 metadata。
- 边界路径：cancel 时工具正在等待 reviewer 审批 → 立即终态化为 aborted；cancel 时无 active runner → interruptedToolState 仍终态化 open tool。
