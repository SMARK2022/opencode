## 上游与目标行为差异明细
- per-file 原子化的失败语义：单文件 apply 失败时收集该文件错误并 continue——最终结果按文件粒度成功/失败列表返回，模型可精确重试失败文件。
- BOM 差异诊断：Bom 工具（@/util/bom）参与上下文匹配的前置归一，BOM 不匹配归入"上下文漂移"类并提示 BOM 存在。
- Watcher 时序：patch 落盘 → Watcher 事件 → EventV2Bridge 广播的顺序保证模型侧 snapshot 读取不早于磁盘写入。
- 与 0347 的关系：0347 覆盖 write 的 input 持久化，本项覆盖 patch 的应用语义——两者共同构成"模型所见 = 磁盘所是"的 harness 不变量。

- apply_patch 的原子化粒度以文件为单位（非 hunk）——hunk 级回滚会引入部分应用的中间语义，文件级为 source 设计决策。
- InstanceContext 的用途：patch 应用时解析相对路径与 worktree 边界，与 0347 的 worktree 参数化（buildParentInspectedFilesSummary）同源。
