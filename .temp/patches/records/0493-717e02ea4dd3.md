## 关键设计决策

1. **ColdStorage 落 core**：core projector 需消费 replace*/release*；opencode 经 `@opencode-ai/core/storage/cold-storage` 引用——依赖方向 core←opencode 合法。
2. **TxOrDb = Sqlite.DrizzleClient**；`Database.Service.sync` 与 `Database.client()` 同一 #sqlite 原生连接；pageCount/VACUUM 用 `(db as Db).$client` 收窄。
3. **schema.gen.ts 必须同步 DDL**：fresh DB（测试/新装）走 DDL 不走 migration——曾致 `no column named cold_ref` 41 例失败。
4. **Forked aggregate=targetSessionID**：EventV2 `commitDurableEvent` 读 `event.data[durable.aggregate]`；锚定 target 与 projector clonePrefix 写入目标一致。
5. **fork 不预热 cold prefix**：rawForkRows 不经 decoder；clonePrefix 在事件事务内完成 refcount 增量与 usage 重放。
6. **worker 启动初始化共享连接**：`AppRuntime.runPromise(Database.Service)`（AppLayer 含 Database.node，全局 memoMap 与后续 instance 复用同连接）——否则 maintenance 在任何 instance 加载前 `client()` 硬失败。
7. **getPart 走 cold-aware decoder**：direct read 与批量 hydrate 共享 `decodePartRow`（thawPartRows + isPart 校验）——corruption fail-closed 由 cold.test "fails closed on a corrupted payload" 实测。
