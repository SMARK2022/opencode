## 行为语义细节（第七波补充核验）
- 分类矩阵：git bundle create <file> <ref> → cautious（需审批确认后放行）；
  git bundle verify / git bundle list-heads / git bundle index 等读取形态 → general（不提升）
- 威胁模型：bundle create 将任意 refset 写入单文件归档——若按 general 放行，
  precheck 的文件写出审批可被"创建归档"这一合法子命令绕过，实现未审批的内容外带；
  cautious 语义使该形态进入既有审批流，与 force-push 同级处理
- 测试配对：positive（create → cautious）与 negative（verify/list-heads → general）
  双向断言齐备，物化于 precheck.test.ts:917-920；precheck.ts:1109-1111 为生产 owner
