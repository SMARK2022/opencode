## 4. Implementation (hunk map)

### pending-tool-input.ts (new file)
- `PendingToolInputStats`: `{ filePath?, fileCount, added, removed }`
- `PENDING_TOOL_INPUT_PROGRESS_INTERVAL = 200` (→ #189 changes to 50)
- `createPendingToolInputParser(tool)`: dispatches to edit/write/apply_patch parsers; unknown tools return empty.
- `createEditInputParser`: scans `filePath`/`oldString`/`newString` via JSON string field scanner; added=newString lines, removed=oldString lines.
- `createWriteInputParser`: scans `filePath`/`content`; added=content lines, removed=0.
- `createApplyPatchInputParser`: scans `patchText`; parses `*** Update/Add/Delete File` headers + `+`/`-` diff lines.
- `createLineCounter`: incremental char/newline/tail counter (no full-text buffer).
- `createJsonStringFieldScanner`: minimal JSON string-field state machine (inString/escaping/unicode), only scans declared fields, never reparses full buffer.
- `formatPendingCounts`: pure function for UI headline contract (` -N +M` order in #187; #189 swaps to ` +N -M`).
- `formatPendingPathLabel`: pure function for path/fileCount label.

### session/index.tsx
- Import `createPendingToolInputParser`, `formatPendingCounts`, `formatPendingPathLabel`, `PENDING_TOOL_INPUT_PROGRESS_INTERVAL`, `PendingToolInputStats`.
- `createPendingToolInputStats(part)`: signal-based stats; `createEffect` watches `part().state.raw`; incremental `push(delta)`; 200ms (→50ms) throttle via `setTimeout(flush)`.
- `PendingStats`: JSX spans with `theme.diffAdded`/`theme.diffRemoved`.
- `Write`/`Edit`/`ApplyPatch`: each gets a `*PendingStats` + `*Pending` memo; falls back to "Preparing..." when no stats.
- `InlineTool`/`InlineToolRow`: `pending: string` → `pending: JSX.Element`; fallback render uses `box flexDirection="row"` with `Show` to support both string and JSX.
