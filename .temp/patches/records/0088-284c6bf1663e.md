### bash-compress.ts 变更
1. detectHighEntropyType 函数：在 return 'unknown' 之前添加 CLIXML 检测

   - 返回 'powershell-clixml' 类型标识

2. transformPowerShellClixml 函数（新增）：
   - 输入检查：trimmed.startsWith("<Objs") 或正则匹配 <Objs
   - 文本提取：/<S\s+S="[^"]*">([^<]*)<\/S>/gi 提取 <S> 节点文本
   - 十六进制解码：clixmlDecodeHexEscapes() 解码 _xHHHH_ 转义
   - ANSI 清除：ANSI_GLOBAL_RE 清除终端颜色码
   - 换行统一：\r\n → \n
   - 输出包装：<high-entropy powershell-clixml> 标签
   - 非 CLIXML 输入返回 null

3. clixmlDecodeHexEscapes 函数（新增）：
   - 正则 /_x([0-9A-Fa-f]{4,})_/g 匹配十六进制转义
   - String.fromCharCode 解码为字符

4. compressVisibleOutput 步骤 "0a"：
   - 在 emptyStats 定义之后、enabled 检查之前
   - 调用 transformPowerShellClixml(text)
   - CLIXML 检测到时直接返回解码结果，跳过主压缩流程
   - 返回 CompressResult { text, stats } 格式
