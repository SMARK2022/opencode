## Port decision summary

Allow the user to Resume a goal whose status is `complete`. The data layer set function already
imposes no state-transition restriction, the HTTP API and prompt loop already support
complete → active, and the only missing piece was the UI not exposing the Resume option for the
complete state. This item adds `complete` to the Resume condition in the goal dialog menu and
adds a regression test locking the complete → active transition plus the usage-preservation
invariant.
