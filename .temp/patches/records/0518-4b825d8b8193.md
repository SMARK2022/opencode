## source 意图重建（original 逐 hunk）
- **coordinator（新文件）**：process-local `queues: Map<canonicalPath, {semaphore, users}>`；`read(fs, path)` 返回 `{path, canonicalPath, version, bytes}`，version 三态 `absent|file(fingerprint)|other(kind)`；`commit({fs, expected, execute})` 在 Permission 后注册 key，按 canonical 字典序嵌套获取全部锁，逐项 recheck（重新完整 read，不信任缓存），全部通过才执行 `execute`，`ensuring` 释放；`MutationConflict` 为诊断性错误（消息含 "changed"）。invariant：version 与 bytes 同源同读；absent≠empty；register 去重防自死锁；users 引用计数防 entry 被误删。
- **apply_patch**：`processSingleHunk` → `groupHunks`（canonicalPath 归组）+ `validateOwnership`（Permission 前拒绝交叉 source/destination ownership 与同 source 混型操作）+ `processHunkGroup`（同 source 多 Update File entry 共享一次 proposal read、每 entry 独立调用 Patch owner、working copy 链式传递、move destination canonical 等价容忍）；每 change 携带 `expected: MutationRead[]`；整 patch 一次 `Mutation.commit`（所有 source+destination recheck 后统一写盘）；`File.Event.Edited`/`FileWatcher.Event.Updated` 移到 commit 成功后发布。
- **edit**：删除 edit 私有 Semaphore 锁；proposal 阶段 `Mutation.read`（Permission 不持锁）；create/edit 两分支均 `Mutation.commit` 包裹写盘与 formatter；保留 0514 裁定的 create throw-on-existing 边界（与源"create 允许覆盖 unchanged"分歧已记入注释与 record）。
- **write**：`Mutation.read` proposal → ask → commit 包裹 writeWithDirs/format/Bom.syncFile；`finalSource` 在锁内读取（metadata 不引用另一 mutation 的中间内容）。
- **测试**：concurrency 10 用例（repeated entry cursor、overlapping move ownership 拒绝、absent→empty Permission 窗口冲突、ask 先于 commit lock、不同 key 并行、formatter 在 critical section 内、取消 waiter 不阻塞后续、apply_patch 外部变更拒绝、multi-file 全量 recheck 无 partial commit、write 先提交后 stale edits[] 被拒）；apply_patch.test 新增 repeated-identical 与 canonical-equivalent（symlink alias）move destination 两用例。
