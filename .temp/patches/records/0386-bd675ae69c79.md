## Source intent

DialogGoalMenu 使用 DialogSelect 只有 3-4 个选项，对话框仅占屏幕 ~20%。本提交：

1. 新增 DialogSelect `header` prop：渲染在 title/filter 与 scrollbox 之间，增加对话框有效高度。
2. DialogGoalMenu 新增 `goalHeader` memo，用两行 wrapMode=none + overflow=hidden +
   `Locale.truncate` 显示 goal objective 截断摘要（68 chars）与 status/tokensUsed，
   保证可预测行数；菜单选项 description 同时截断到 60 chars，避免 4000 字符 objective
   在选项行换行导致 rows() 计算不准。
3. max_turns 语义修复：goalTurns 达到 maxGoalTurns 后 loop 退出但 goal 状态保持
   active，UI 误导用户。新增自动 pause：`maxGoalTurns > 0 && !session.parentID &&
   goalTurns >= maxGoalTurns` 且 goal.status === active 时 `goalSvc.set({ status:
   "paused" })`。守卫：maxGoalTurns=0（禁用续跑）不 pause，complete/blocked 不 pause；
   Resume 后新 loop 以 goalTurns=0 重新累计。
4. 默认 max_turns 从 10 提升至 32（配置字段 + session prompt 回退值 + 测试断言）。
