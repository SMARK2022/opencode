## 2. Three-way design

### Upstream (post-#79 target notebook stack)

Upstream already has VS Code notebook extension handlers under `sdks/vscode/src/notebook/*` with resolve-by-filePath, run/edit/source/summary/output/env, and cell identity via `#VSC-*` ids after earlier SMARK notebook work. Run historically accepted broader targets (`all`, nested payload shapes) and could fall back to the active notebook when `filePath` was missing. Wait semantics in early target paths were weaker (timing-only or success-optional depending on intermediate currents).

### Source / SMARK (original #80)

Original removes run `all`, flattens CLI/plugin payload to top-level `type|cellId|endCellId`, makes `filePath` required on every notebook tool entry, deletes `notebookRange` helper, hardens edit to apply+wait, and makes run wait complete only when `executionSummary.success` is a boolean. Critically, **`endCellId` is the range signal**: if present and distinct from `cellId`, the run expands to an inclusive cell range; reverse order throws. `type` is documentation/validation, not the sole range gate.

### Target adaptation (this current)

Rebuild on post-#79 owners without inventing a second HTTP API:

1. **commands.ts** — quick-pick only `cell|range` (no `all`); messages match flat args.
2. **run.ts** — `resolveRunTarget(notebook, type?, cellId, endCellId)`:
   - normalize ids by stripping leading `#`;
   - if `endCellId` present and `norm(endCellId) !== norm(cellId)` → inclusive range;
   - if caller also set `type === "cell"` with a different end → throw (SMARK #84 guard layered early so cumulative state never silently ignores mismatch);
   - reverse range (`end.index < start.index`) throws;
   - wait: pre-register `waitForSingleCell` → execute → `wait.promise`; complete only when `typeof success === "boolean"`; timeout writes SMARK timed-out `exec` text and `failedIndex`.
3. **resolve/env/output/source/summary** — required `filePath`; no active-notebook fallback.
4. **edit.ts** — `applyNotebookEditAndWait` / `applyTextEditAndWait` primary path.
5. **resolve.ts** — drop `notebookRange` export (orphaned JSDoc may remain; no callers).

URI identity for waiters is retained as a target strengthening on the same success-boolean path (not a timing-only alternate).
