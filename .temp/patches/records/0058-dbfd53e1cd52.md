OpenTUI can use system `wcwidth`; under compiled Bun on macOS, locale/native wcwidth may return -1 for CJK, rendering empty cells. Env `OPENTUI_FORCE_UNICODE` selects built-in Unicode width tables.

V2 uses expression form `try: () => createCliRenderer({...})` so multi-statement env setup requires an async block body.
