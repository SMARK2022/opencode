## 2. Upstream design
TUI renderer is created in `packages/tui/src/app.tsx` inside Effect `tryPromise` → `createCliRenderer(...)`. OpenTUI can use system `wcwidth`; under compiled Bun on macOS, locale/native wcwidth may return -1 for CJK, rendering empty cells. Env `OPENTUI_FORCE_UNICODE` selects built-in Unicode width tables.

V2 uses expression form `try: () => createCliRenderer({...})` so multi-statement env setup requires an async block body.

## 3. SMARK source design
On `darwin` only, before creating the CLI renderer: `process.env.OPENTUI_FORCE_UNICODE = "1"`.

  if (process.platform === "darwin") {
    process.env.OPENTUI_FORCE_UNICODE = "1"
