## source 行为重建
- 集合式编辑：同一次 apply_patch 调用内，同 canonical 文件全部 update entries\chunks 拍平后对 immutable original 定位；context 只作 chunk-local 下界（locateContext）；全部成功后 spans 按 start 升序排序、相邻半开区间 overlap 检测（`Overlapping expected lines`）、reverse apply 到 original 副本；pure insertion 按 patch 顺序追加 EOF。
- locateExact 候选清单化：exact whole-line\normalized whole-line 同层参与唯一性（多候选 → ambiguous，废止 first-hit 与 EOF 提前成功）；exact literal occurrences 与 normalized proper substring（normalizedRawView：逐 grapheme 归一化 + raw boundary map\gaps\owners；不可映回的 occurrence 计入 unsafe 唯一性计数）属 lower tier；exact 层存在时 lower tier 不否决既有成功域。
- groupUpdateHunks：只聚合同 canonical source 全为 update 的 hunks（mixed add\delete 不聚合）；move destination 冲突拒绝；direct apply 与 verified preview 共用 grouping（INV-11 consumer parity）。
- Tool update case：单 snapshot、单次 `deriveNewContentsFromChunks(chunks)`，entry2 不读 entry1 生成文本；BOM\diff\计数均来自单次派生结果。
- 测试意图：乱序唯一 chunk 一次成功（Session 症状）、context 独立、whole-line 歧义拒绝、nested literal 层级、overlap 拒绝、PI 矩阵（trimEnd/NFKC/nbsp/标点；不 trimStart）、grapheme 边界（A+̊ \nﬃ 完整可映射、半个 ﬁ expansion 不可）、unsafe occurrence 参与唯一性、exact+normalized 同层歧义、repeated context first-eligible、EOF 不做歧义选择器、exact substring 优先于 fuzzy、repeated entries\alias 三 consumer（Tool\verified\direct）parity。
