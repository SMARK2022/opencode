# Record 0107-f0f0c3a6ddb3

## Source intent
SMARK 在 Prompt 根 `box` 上增加 `renderBefore` 钩子：每帧绘制前，若 `this.screenY` 有效且小于 buffer 高度，则对 `(screenX, screenY)` 起宽 1、高 `buffer.height - screenY` 的矩形做透明填充，清掉 prompt 下方因滚动残留的 ghost 像素。

Original 还导入 `OptimizedBuffer` 类型以标注回调参数。

## 上游 / tip@106 设计
- Prompt 已从 `packages/opencode/src/cli/cmd/tui/...` 迁到 **`packages/tui/src/component/prompt/index.tsx`**。
- 依赖 `@opentui/core` 0.4.x；`OptimizedBuffer` 公开方法为 **`fillRect`**（见 `node_modules/@opentui/core/buffer.d.ts`）。历史源码字面量 `fillsRect` 在 tip 上不存在。
- 渲染链路：`Renderable` 在无 try/catch 的情况下直接调用 `renderBefore(buffer)`——错误方法名会变成运行时 TypeError，而不是静默跳过。
