## Port decision summary

The upstream commit changes the `DialogPrompt` textarea from a fixed `height={3}` to the
`minHeight={3}` + `maxHeight={9}` pair so that (a) the empty state keeps enough visual space and
(b) long text (e.g. a 4000-char goal objective) grows the textarea instead of being clipped to a
3-line window. This matches the main Prompt component's `minHeight`+`maxHeight` growth pattern
(see `packages/tui/src/component/prompt/index.tsx:1588-1589`), which this series already uses.
The port is verbatim: the same three Chinese comments and the two attribute lines are carried
over unchanged, re-anchored on the local `textarea` JSX block.
