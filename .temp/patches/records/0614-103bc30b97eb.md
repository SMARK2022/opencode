## source 行为重建
- **卡死根因**：急 `sessionUsage` memo 使每个 part delta 重算 tokenAccounting（300 消息 ~15ms/delta），饿死 process.nextTick；reconciler 的 deferred-destroy 无界积压至 native 句柄注册表（65,535）耗尽 → `Failed to create TextBuffer` → TUI 冻结。
- **exit 惰性化**：`ExitMessage = string | (() => string | undefined)`；message.set 放宽接受 producer；get 在求值时调用函数形态；字符串调用方（sync 的 "opencode daemon stopped."）零改动。
- **session 路由**：删急 memo + per-delta effect；改一次性 `onMount(() => exit.message.set(() => { …tokenAccounting… }))`——退出时对最终快照求值，数字语义不变（output+reasoning 合并、cache 排除）；**刻意不 onCleanup 还原**（路由卸载≠进程退出）。
- **测试**：INV-02 惰性锁——5 个 part delta 后 setCount 保持基线（ExitCapture 包装计数）。
- **smark.12 采纳**：manifest/lock/peer 全量 .11→.12 + gitlink 0f64a76e→2145b934（reconciler bounded-destroy 修复经子模块承载）。

## 目标事实与适配（语义移植映射）
- **owner 迁移**：source 的 `cli/cmd/tui/context/exit.tsx` message store 在目标不存在（目标是 ExitSignals void-exit 设计）——等价 seam 是 **epilogue 面**：`packages/tui/src/context/epilogue.tsx`（set(string)）+ `app.tsx:253/350/452/461`（exit.epilogue 存储/打印）+ `session/index.tsx:277/:285-296`（#490 的急 memo + effect + onCleanup 还原）。
- **移植三处**：
  1. epilogue.tsx：set 签名放宽 `string | (() => string | undefined)`（镜像 source 的 ExitMessage 放宽）。
  2. app.tsx：exit.epilogue 类型放宽；`Tui.run` 返回边界（Deferred.await(shutdown) 后）`typeof === "function" ? epilogue() : epilogue` 求值——惰性边界与 source 的 exit 时求值同构；:461 打印不变（届时已是 string）。
  3. session/index.tsx：删 `sessionUsage` 急 memo + per-delta `createEffect(setEpilogue(字符串))` + `onCleanup(() => setEpilogue())`；改 `onMount(() => setEpilogue(() => { tokenAccounting 最终快照 … }))`——急路径消除是根因修复本体；不还原 onCleanup 是 source 同款决策（保留注释说明）。
- **测试移植**：`session-exit-lazy.test.tsx`（新文件）——完整 session harness 挂载成本过高，按 #491 call-site 契约测试先例对生产源码做 fail-capable 断言：onMount producer 存在 / `sessionUsage = createMemo` 缺席 / per-delta setEpilogue effect 缺席 / app.tsx 退出边界求值存在 / epilogue set 签名承载 producer。加上既有 app-lifecycle.test.tsx（epilogue 打印回归）双覆盖。
- **丢弃段（SUPERSEDED_BY_REGISTRY）**：bun.lock ×4、根/core/opencode package.json overrides ×3 段、plugin peer——目标 registry 0.4.5 catalog 形态无 smark tarball URL/版本字符串（0613 同款裁定）；gitlink 0f64a76e→2145b934 verbatim 承载源指针追踪（preimage 与 0613 postimage 精确衔接，链自洽）。
