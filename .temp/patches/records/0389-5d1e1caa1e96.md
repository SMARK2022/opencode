## Source intent

1. prompt footer 宽屏移除上传/下载的累积量括号：UsageInfo 删除 totalInput/
   totalOutput 字段，宽屏分支只显示当前 step 的 ↑/↓ 分拆值，累积量改由
   sidebar 承载，消除双处冗余。
2. `showCumulative` 改名为 `showSplitFlow`（语义从"是否显示累积括号"变为"是否
   分拆上下行流量"），阈值由 >100 下调至 >90，让中小终端也能看到分拆；
   voice 提示阈值由 >140 下调至 >120（`VOICE_HINT_MIN_PROMPT_WIDTH`），保持
   voice 晚于 usage 的露出梯度（120 > 90）。
3. sidebar Context 上下载括号改用 `Locale.number`（K/M 缩略）与 prompt 流量
   格式对齐；总量行保留 toLocaleString 全精度作为权威读数。
4. 同步更新 voice 边界断言（140/141 → 120/121）与 prompt 渲染断言
   （totalInput/totalOutput → Locale.number 分拆渲染）。
