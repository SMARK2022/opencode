## Source intent
Seven surgical enhancements to the notebook tool family so the agent can
manage the notebook lifecycle autonomously:
1. withFileLock bypass for read-only ops (summary/source/output no longer
   blocked by a long-running run)
2. env `stop` operation via `jupyter.interruptkernel` (interrupt the timed-out
   cell, keep kernel state)
3. env `create` operation (structured .ipynb creation instead of raw-JSON
   writes; inherits the general `edit` gate because it writes a file)
4. run-time kernel pre-check (no active kernel + no kernelspec metadata →
   guide configure first; avoid silent failure/picker loops)
5. restart light-weight verification via `isKernelAccessible` (getKernel only,
   no executeCode probe delay)
6. readJson friendly error (body length + interruption hint)
7. tool-wide error recovery guidance (run timeout → env stop/info; file not
   found → env create; execute unavailable → install Jupyter + configure)
Plus a 742-line plan doc `docs/notebook-tools-enhancement-plan.md`.
