## Source intent
`SubagentFooter` extracts the agent name from the session title with the regex
`/@(\w+) subagent/`. `\w` does not include `-`, so for the reviewer subagent
(`@permission-reviewer subagent`) the `\w+` matcher stops at "permission",
the overall regex fails to match, and the footer label falls back to the generic
"Subagent". Fix: widen the character class to `[\w-]+`. This is a strict
superset of `\w+`, so hyphen-free agent names (general/explore) behave
identically, and the existing fallback when the title has no `(@… subagent)`
marker at all is unchanged.
