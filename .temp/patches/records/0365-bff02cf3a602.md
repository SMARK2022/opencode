## Source intent
`classifyGit` only inspected `tokens[1]` as the subcommand, so dangerous git
subcommands such as checkout/switch/restore/stash/config/remote/tag/apply/am/
filter-branch/update-ref/bisect/symbolic-ref/worktree/submodule fell into
`general` (auto-allowed). Global flags (`-C`/`-c` etc.) placed before the
subcommand also bypassed every cautious check. The fix: a single-pass loop
that skips flags to locate the real subcommand while detecting unsafe global
flags and promoting them to cautious. Conditional checks keep read-only
exceptions for stash/config/remote/tag (stash list, config --get, remote -v,
tag -l, etc.); a bare `git config` with no arguments stays general.
`GIT_UNSAFE_GLOBAL` is extracted from `gitSafe` into a module-level constant
shared by both functions.
