## Port decision summary

Sub-agents that return empty text now receive one synthetic "nudge" round so they at least
produce a text reply. The nudge neither restricts tools nor overrides instructions nor imposes a
format — the task requirements remain defined by the main agent's original prompt. When abort has
already fired the nudge is skipped (an aborted signal will never re-fire the abort event, so a
fresh runner created by the nudge could not be cancelled afterwards and would waste tokens). The
static fallback string now includes a resume hint guiding the main agent to continue via the
task_id.
