## Source intent
Two small CI/test hardening changes:
1. CI environment sets `OPENCODE_DISABLE_LSP_DOWNLOAD=true` for the workflow
   env. GitHub macOS/Windows runners ship a .NET SDK, so spawning the CSharp/
   FSharp LSP server triggers `dotnet tool install` of roslyn-language-server;
   that download blows past the 30s cap on the BOM test (a .cs file spawns the
   CSharp server). Every LSP server with auto-download checks the flag in its
   spawn path, so one env var covers all of them.
2. Three shell tests that assert on echo output get `; sleep 0.01` appended to
   the command. With `detached: true` + Bun scheduling jitter, the pipe/command
   can exit before stdout has been flushed to the pipe on macOS CI; the basic
   test already used this pattern.
