## Source intent
Add a session-level persistent goal state machine
(active/paused/complete/blocked). When the agent loop ends normally and the
goal is still active, inject a continuation prompt and auto-continue the loop.
The continuation prompt text aligns with Codex continuation.md and includes
Completion audit (8 verification rules), Blocked audit (3-consecutive-turn
rule + anti-lazy-block), Fidelity (no goal narrowing), and Work from evidence
(inspect current state, not memory). The model can only mark complete/blocked
via the goal tool; users control the goal lifecycle through the HTTP API
(GET/POST/DELETE /session/:id/goal). The TUI sidebar gains a goal panel
(status + objective + usage), the footer shows active/blocked, and the message
panel renders continuation prompts with a "↻ Goal continuation" label. Gated
by `experimental.goals` (default off) with `experimental.goal_max_turns`
(default 10). Subagent sessions and decide agents do not participate.
