## 补充详情

### compactionMessageIDs 语义
- 只收集 user 消息。若消息含 compaction part（type === "compaction"）且该消息没有任何非 synthetic 的实际 text part，则认为它是纯压缩边界标记（interrupted marker）。
- synthetic/ignored 过滤避免把某个用户真实输入的重复文本误判为纯标记。当 compaction 发生在用户消息之后且该用户消息本身有正文时，不标记为边界行。

### drawSessionScrollbar 的 marker 复用
- source 用 Math.max(0, child.screenY - s.content.screenY) 内联在 return 中；适配提取为 offset 变量，供 compaction 分支和普通 agent color 分支复用，避免重复计算。
- theme.borderActive 是 RGBA，与 SmoothScrollbarMarker.color 类型兼容（smooth-scrollbar.ts:12 导出 { offset: number; color: RGBA }）。
- compaction marker 颜色语义：compaction 边界是持久化事件，用 borderActive（主题强调色）而非 user message agent 色，避免与普通 prompt 混色。

### box id 语义
- id={text() ? undefined : props.message.id}：只有当用户消息没有正文（纯 compaction marker）时才把 message id 挂到 box 上，供 scrollbar 的 compactionMessageIDs 命中；有正文时 id 为 undefined，不影响原有布局查找。

### 测试跳过理由
source session-message-render.test.tsx 的 2 个 new 测试（auto compaction boundary labeled / session scrollbar marks compaction boundaries）依赖 withRenderedSession + clickVisibleText + waitForFrame 测试基础设施，target TUI 迁移时未带入该 harness（target 用 @opentui/solid testRender 隔离组件级测试，session route 无全量渲染 harness）。0292 已跳过该文件同因。行为由生产代码承载：compactionMessageIDs + drawSessionScrollbar + box title 已实现，typecheck 验证类型正确。
