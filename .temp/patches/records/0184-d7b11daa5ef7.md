## 1. Source intent

Correct session message **readable width** so wrap/diff/reasoning budgets match real OpenTUI/Yoga columns.

Broken formula on tip before this patch:

```ts
contentWidth = terminalWidth - (sidebarVisible ? 42 : 0) - 4
```

Failures:

1. **Overlay vs docked sidebar** — narrow terminals use absolute overlay sidebar; subtracting 42 still crushed message width.
2. **Missing chrome** — main L/R padding (~4), message left border+padding (~4), scrollbar gutter (~2) not modeled.
3. **Magic 42** duplicated in session index and sidebar.

Correct pure function:

```
max(1, terminalWidth
  - (sidebarInLayout ? SESSION_SIDEBAR_WIDTH : 0)
  - 4  // main horizontal padding
  - 4  // message left chrome
  - (scrollbarEnabled ? 2 : 0))
```

with `sidebarInLayout = sidebarVisible && wide` (wide ≈ terminal width > 120).
