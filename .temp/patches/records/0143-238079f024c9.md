### listByProject control flow (tip)
```
if (input.path !== undefined) {
  // includes path === ""
  projectPath = or(...relatedPathConditions({ path, directory, global: isGlobal, root: true }))
  useDirectoryFallback = directoryMatchesPath(...)
  globalPath = optional relatedPathConditions from SessionPath.relative("/", directory) when fallback
  nullPath = legacy null path + directory match
  conditions.push(or(
    and(project_id == input.projectID, projectPath|nullPath),
    optional and(project_id == "global", globalPath|nullPath),
    optional relatedDirectoryConditions(directory),
  ))
} else {
  conditions.push(eq(project_id, input.projectID))
  // optional directory equality for non-path lists
}
```
Key invariant comment: **path 只要定义（含 worktree 根 ""）就必须走 related/global OR，禁止回退 project_id**.
