## 3. SMARK Intent
- 用户可见行为：shell 工具流式输出时，metadata.output（默认 live UI 表面）显示终端重绘后的稳定文本，CR 进度和清行重绘不泄漏原始控制字节；完成时 metadata.output 保留最终终端屏幕快照。
- 受保护不变量：`metadata.output` 是显示通道，非忠实模型返回通道；`result.output` 仍走原始压缩/截断路径；空终端屏幕（清行/清屏后）是合法显示状态。
- 正常路径：chunk 到达 → `display.push(chunk)` → `preview()` → metadata.output = visible；完成 → `preview(display.value())` → metadata.output = displayOutput。
- 边界路径：无 chunk 到达（displayed=false） → metadata.output = preview(output)（回退到原始压缩输出）。
