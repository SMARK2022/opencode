## 2. Upstream design
Prompt component (`packages/tui/src/component/prompt/index.tsx`) hydrates agent/model/variant from the last user message when sessionID changes. local.model / local.agent are process-global. Session UI can unmount/remount Prompt when the context panel toggles (contextVisible) or permission/question overlays show.

Old pattern: component-local syncedSessionID + reactive lastUserMessage() dependency.

## 3. SMARK design — two bugs
Bug A: messages load asynchronously after mount; reactive last-user re-runs the effect and overwrites a mid-session model switch.
Bug B: remount resets syncedSessionID, so hydration runs again and clobbers the user model.

Fix: module-level initializedSessionIDs Set survives remount; untrack(lastUserMessage) so only props.sessionID drives the effect; claim session only after a last user message exists.

## 4. This adaptation
Import untrack; module Set above stashed; replace effect body with empty-session skip, already-initialized skip, untrack msg, claim Set, then primary-agent + model/variant sets. Chinese comments for Bug A/B and Set purpose.

## 5. Intentional tradeoffs (source-faithful)
Re-visiting a session ID later does not re-hydrate. If first run has sessionID but empty messages, no claim and no later hydrate until remount with messages (anti Bug A).

## 10. Call chain
1. User opens or switches session → Prompt mounts with `props.sessionID`.
2. Effect hydrates agent/model/variant from last user message once per session id.
3. User can change model mid-session via local state.
4. Context panel or permission overlay can unmount/remount Prompt without changing session id.
5. Without module Set + untrack: remount or late message load re-runs hydration and overwrites step 3.

## 11. Interaction with local store
`local.model` / `local.agent` are process-global maps keyed by agent name. Hydration writes into those maps. The Set only gates *whether* hydration runs; it does not snapshot model values. That matches SMARK: one hydrate claim per session id for the component lifetime of the process.

## 12. Residuals
No pure unit test in this index. Later UI refactors that stop remounting Prompt reduce Bug B frequency but do not replace the Set invariant for async message load (Bug A).
