# Record 0110-b6690c2cc860

## Source intent
SMARK 修复 Windows/Bun 下 VSIX 打包失败：

1. **删除** `package.json` 中 `"vscode:prepublish": "bun run package"`。原因：`vsce package` 会通过内部 `npm run vscode:prepublish` 再起子进程；部分 Windows 终端里该子进程 PATH 丢失 npm，报错 `'npm' is not recognized`。
2. 推荐/脚本路径改为：**先**显式 `bun run package`（typecheck+lint+esbuild），**再** `npm exec --yes --package @vscode/vsce -- vsce package --no-dependencies -o dist/SMARK2022.opencode-ide-bridge-<ver>.vsix`。
3. 版本号与 CLI 发布对齐（source 写 1.14.32；tip 上 CLI 经 #109 已是 1.17.21-smark，故 VSIX **1.17.21**）。
4. 文档（`docs/VSIX-Packaging.md`、README）更新版本表、dist 路径、prepublish 失败样例与“项目故意不定义 prepublish”的说明。
