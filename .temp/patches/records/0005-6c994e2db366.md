## 3. SMARK Intent

- User-visible behavior: Throttle usage/state signal updates to 50ms to reduce UI re-render frequency during streaming. Estimate tool output tokens from `part.state.output.length` for tool results after the last `step-finish` to provide real-time input token feedback during streaming.
- Protected invariant: Throttle uses leading-and-trailing edge: first update immediate, trailing update ensures final value is always flushed. Tool-output estimation only active during streaming (`!last.time.completed`); once complete, API's `input_tokens` already includes tool outputs.
- Normal path: `usageRaw`/`stateRaw` memo computes raw values → `createEffect` feeds to throttled setter → throttled signal provides debounced value to JSX.
- Boundary and error paths: No tool parts after step-finish → `toolOutputChars = 0`. Message complete → `toolOutputChars = 0` (skip estimation). No last assistant message → return undefined.
- Concurrency/exit/cleanup/security paths: `onCleanup` in `createThrottledSignal` clears pending timer.
