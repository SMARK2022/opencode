## Source intent（original 完整语义）
本 commit 标题是「添加对 VS Code 笔记本的运行和环境选项支持，优化单元格 ID 解析逻辑」。original 三个文件、三个语义轴：

### agent.ts
在 permission 配置中、与 `bash: "ask"` 同一对象字面量内新增：
- `vscode_notebook_run: "ask"`
- `vscode_notebook_env: "ask"`
意图：交互审批代理执行 notebook 运行与环境操作时，与 bash 一样需用户确认，而不是静默 allow。

### vscode-bridge.ts
`runArgs.cellId` 的 Zod `.describe(...)` 从仅说明 `#VSC-xxxxxxxx` 扩展为同时说明 **TOP / BOTTOM** 表示首/末 cell。这是 schema 层对 agent 可见的契约文档，不是运行时解析本身。

### run.ts
`resolveRunTarget` 内引入局部函数 `resolveCell(id)`：
- `id.toUpperCase() === "TOP"` → `notebook.cellAt(0)`
- `BOTTOM` → `notebook.cellAt(Math.max(0, notebook.cellCount - 1))`
- 其它 → 既有 `resolveNotebookCell(notebook, undefined, id)`
`startCell` 与 range 的 `endCell` 都改为 `resolveCell`。空 notebook 时 BOTTOM 仍用 max(0, count-1)，与 source 一致。

无测试文件、无 schema migration、无文档文件。
