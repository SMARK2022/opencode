## 3. SMARK Intent
- 用户可见行为：点击 task 工具时，先强制刷新子代理会话数据再导航，确保用户看到的是实时 agent 视图而非可能为空的缓存快照。
- 受保护不变量：force-refresh 绕过 `fullSyncedSessions` 缓存——prefetch（onMount）标记的 "已同步" 不阻止显式导航获取最新数据。
- 正常路径：Task onClick → `sync.session.sync(sessionID, { force: true })` → `navigate({ type: "session", sessionID })`。
- 边界路径：子会话消息尚未到达 → force-refresh 拉取最新；子会话已同步且非空 → force-refresh 仍重新拉取（保证一致性）。
