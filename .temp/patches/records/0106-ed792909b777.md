# Record 0106-ed792909b777

## Source intent（original 完整语义）
本提交在会话消息分页与列表路径上引入 `includeHidden` 契约：

1. `MessageV2.page` 增加可选参数 `includeHidden?: boolean`（默认 false）。
2. 当 `!includeHidden` 时，在 hydrate + reverse 之后：
   - 删除 `info.hidden === true` 的消息；
   - 过滤各消息 `parts` 中 `hidden === true` 的 part。
3. `MessageV2.stream` 调用 `page` 时固定传入 `includeHidden: true`，由 stream 自身按 `opts?.includeHidden` 再过滤——这样分页游标走全量历史，输出仍可默认隐藏。
4. `Session.messages` 在 `limit` 分支去掉对 `page().items` 的二次 `.filter(m => !m.info.hidden)`，避免与 page 默认过滤重复。

## 上游 / tip@105 设计
- tip 已将 `page` 改为 `Effect.fn`，依赖 `Database.Service`，失败时 `NotFoundError`。
- tip `stream` 已是 Effect.gen，带 `opts.includeHidden` 与 part 级过滤（#98 软隐藏）。
- tip `Session.messages`：limit 路径仍二次 filter；无 limit 路径走 stream + reverse（#98 时序）。

上游更强点：Effect 分页、DB 注入、NotFound 处理——必须保留。
