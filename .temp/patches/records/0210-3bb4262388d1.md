## 3. SMARK Intent
- 用户可见行为：read/edit/write/apply_patch 访问项目外路径时，external_directory 门禁携带工具来源证据（action_kind=tool + tool + operation/payload），使 Auto reviewer 能基于工具意图而非仅路径判断；路径型（无证据）请求仍走人工审批。
- 受保护不变量：路径放行不可跨内容复用——tool-origin external_directory 不写入会话缓存，避免同目录 read 放行被后续 write/patch 复用。
- 正常路径：工具调用 `assertExternalDirectoryEffect(ctx, path, {metadata})` → metadata 透传到 `ctx.ask` → auto.ts 识别 tool 证据 → 路由 reviewer。
- 边界/错误路径：无证据 / 证据不全（action_kind=tool 但缺 tool/operation/payload）→ `hasToolExternalDirectoryEvidence` 返回 false → 走人工审批（ask/precheck）；shell-origin 仍复用命令预审（#203 不变）。
