## Source intent
新增 POST /session/preview 端点，用单条 SQL 窗口函数查询一次性返回多个
session 的最近 N 条用户消息文本。TUI switch-session 对话框预览加载从 400+
次 HTTP 分页调用（~10s 阻塞）降至单次请求（~130ms），数据传输从 ~50MB
降至 ~200KB。过滤条件与 MessageV2.page(includeHidden=false) +
textFromUserMessage 完全对齐：EXISTS 子查询确保无 text part 的用户消息
不占排名位；ROW_NUMBER() OVER (PARTITION BY session_id ORDER BY
time_created DESC, id DESC) 只对满足谓词的消息排名，limit 由 payload 传入
（缺省 2）。workspace-routing 新增 /session/preview 路径例外避免
SessionID 品牌校验异常（"preview" 不是有效的 ses_ 前缀 ID）。预览行数
(2)、session 上限 (400)、扫描范围（全部用户消息）均不退化。TUI 侧用
AbortController 取消 in-flight 请求并用 signal.aborted 守卫防止竞态覆盖。
