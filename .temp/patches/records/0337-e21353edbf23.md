## 权限丢失修复详解
- **问题根因**: handleSubtask 传 `task.agent`（子 agent 名如 "general"）给 `taskTool.execute`。task.ts 的 `deriveSubagentSessionPermission` 用 `ctx.agent` 作为 `parentAgentName` 解析父会话 permission ceiling。如果 ctx.agent = "general"（子 agent），parentAgent 被解析为 general 自己的 permission（不含 auto 父会话的 external_directory/bash/edit auto 规则）。
- **auto ceiling 丢失**: TaskTool 派生子会话 permission 时，auto 父会话的 `external_directory: auto`、`bash: auto`、`edit: auto` 规则不出现在 ceilings 中。子会话访问外部目录时落到 ask 弹窗而非 auto reviewer。
- **permission 替换问题**: `session.permission = permissions` 整体替换擦除 TaskTool 派生的 auto ceiling。tool override（如 `task: false`、`todowrite: false`）应追加到已有 permission 之后（last-match-wins），而非替换整个 ruleset。
- **修复**: `agent: lastUser.agent`（父 agent 名）与 Path A 一致。`Permission.compact([...(session.permission ?? []), ...permissions])` 保留 ceiling 同时追加 override。
