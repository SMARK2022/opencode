## 目标 owner 与调用链
- 真实创建 owner 已迁到 packages/opencode/src/cli/cmd/tui.ts 的 spawnDaemon。
- Windows 路径为 CLI、绝对 SystemRoot PowerShell wrapper、WMI relay、Bun worker。
- #532 将创建移入 WMI relay，以避免 launcher 的 kill-on-close job 连带终止 worker。
- relayScript 原来通过 Start-Process 创建 worker，写出 PID 后直接结束。
- wrapper 原来通过 Wait-Process 观察 PID，末尾固定 exit 0，无法取得真实 worker code。
- wrapper.stdout 虽已有 reader/drain，但 WMI relay 的 stdout 不继承这条通道。
- 因此单改旧 wrapper 或把 relay 双流统一排到 Null 都会漏掉 source 的有效语义。
- native owner 为 packages/tui/src/terminal-win32.ts，运行时 detach 函数无需改写。
- worker owner 为 packages/opencode/src/cli/tui/worker.ts，printLogs 判定仍是 argv 或 env。
- 此项属于进程传输 owner，不涉及 V1/V2 Session 编排、数据库 Schema 或消息消费路径。
