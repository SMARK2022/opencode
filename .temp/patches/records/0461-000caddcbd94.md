## Source Intent（核心不变量）
1. Windows 上 SDK 构建挂起根因：`bun tsc` 经 PATH 解析启动 tsc，Bun 的
   进程管理让该子进程在 CI 上悬挂不退。修复：`bun ${Bun.resolveSync(
   "typescript/bin/tsc", dir)}`——定位到 workspace 依赖内绝对路径启动。
2. 其余 ~60 个 gen hunks 是源时代 schema 演进触发的 SDK 再生成输出
   （SessionTodoResponses、TuiSelectSessionResponses、ProviderAuthError1、
   EventPermissionReplied、SyncEventSessionNextCompactionEnded、
   FindTextData 等新类型 + 若干旧变体删除），非手写语义。
