## 语义说明与关键裁决

- **core 分层**：CompactionBoundary/summary 列/PartColdStats 全落 core（opencode 不能反向依赖）；summary-cache.ts 留 opencode（消费 InstanceState/Storage）经 core TxOrDb 互通。
- **db 参数形态**：源 `Database.use/transaction/Client` 同步全局——目标无此 API；全部改显式 db/sync 参数（0493 既定形态），生产与测试一致。
- **事件 summaryOnly**：目标 MessageUpdated schema 在 packages/schema——加 optional 字段为最小改动（无 wire 兼容破坏）。
- **maintain owner 链**：h48/h51 的 message→part→session-summary 三路 else-if 链；summary expand 阶段禁 compress 进入。
- **mirrorGatedStorage**：源靠 Storage 服务注入竞态钩子——目标以 AppNodeBuilder 替换 Storage.node 实现同一竞态窗口（ready Deferred 发布 + release 控制真实 read 延迟），生产零侵入。
- **helper 双消息 turn**：源 addCompletedSummaryEdit 含 userID/assistantID 两 marker（cursor 语义= user marker 为闭界）；适配重建保持该结构（删除 assistant 后 user 仍是合法 cursor 的断言依赖此）。
