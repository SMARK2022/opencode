- User-visible behavior: Split token usage display into "current request" (assistants answering the last user message) vs "session-total" cumulative. The main `input`/`output` numbers represent only the current request; parenthesized numbers show the whole-session total.
- Protected invariant: `requestAssistants` = assistants whose `parentID` matches the last user message's `id`. `sumConfirmed` accumulates `step-finish` tokens across a list of assistant messages. `activeAssistants` fallback (request → all) ensures streaming estimates work even when `requestAssistants` is empty.
- Normal path: Filter assistants → compute `requestAssistants` → `sumConfirmed` for request and global → add streaming estimates from last in-flight message → return `currentInput/Output` + `totalInput/Output`.
- Boundary and error paths: No assistants → return zeros. All tokens zero → return zeros when running. `requestAssistants` empty → `activeAssistants` falls back to all assistants for streaming estimates.
