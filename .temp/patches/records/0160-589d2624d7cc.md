## 附录：算法细节（供审计对照）

### looksLikeGBK
- Scan left-to-right.
- ASCII `<0x80`: skip.
- Lead `0x81..0xFE` + trail `0x40..0xFE` excluding `0x7F`: count validPairs, consume 2.
- Else: invalidBytes++.
- Accept only if validPairs>0 and invalidBytes==0 (strict: no stray high bytes).

### mostlyUtf8
- Count valid multibyte UTF-8 sequences (2/3/4) vs invalid high-byte starts.
- If total==0 (all ASCII): false (do not prefer “mostly utf8”).
- Prefer utf-8 path when validMultibyte > invalidMultibyte.

### decodeAutoSegment order (tip@158+#160)
1. unicode(BOM/NUL)
2. isUtf8 fatal
3. `!looksBinary && looksLikeGBK && !mostlyUtf8` → gb18030
4. else utf-8 (replacement)

### Surrogate truncate
- High surrogate range `0xD800..0xDBFF`; low `0xDC00..0xDFFF`.
- truncate: if `charCodeAt(end-1)` high, `end--`.
- truncateMiddle: if start boundary ends on high, `keepStart--`; if end boundary starts on low, `keepEnd--`; use `slice(-keepEnd || undefined)`.
