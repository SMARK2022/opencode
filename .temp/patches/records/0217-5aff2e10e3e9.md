## 3. SMARK Intent
- 用户可见行为：文件删除/移动操作（rm、unlink、rmdir、del、erase、Remove-Item、mv、move、ren、Rename-Item、Move-Item）路由到 reviewer 而非自动放行；不透明 shell 段（重定向、命令替换、反引号、未建模分隔符）中的破坏性载荷保留 cautious/dangerous 层级；$env:SystemDrive 递归删除判定为 dangerous。
- 受保护不变量：bounded 文件删除/移动为 cautious（reviewer 判断），保护根递归删除为 dangerous（直接拒绝）；包装器内 safe 载荷不传播（仍 general），但 cautious/dangerous 传播。
- 正常路径：命令 → dangerousRaw（短路 dangerous） → cautiousRaw（rawExecutableMatch 文件删除/移动 + 敏感读取） → rawWrapperScripts 递归 → splitCommands → evaluateCommand → riskyTokens（token 级文件删除/移动 + 其他风险） → safeTokens。
- 边界路径：未建模分隔符（`&`、`\n`）让 splitCommands 返回 undefined → rawWrapperScripts 仍扫描各段 → 破坏性命令传播 cautious/dangerous。
