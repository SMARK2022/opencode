## Source intent（original 完整事实源）
Original 针对 TUI context-usage 做两件独立但相关的事：

1. **Breakdown 缺失时的 gather**  
   当 accounting/daemon 未提供 `acc.breakdown` 时，source 仍要从本地或注入源 assemble instructions / skills / tool definitions，使 context 面板能按分类展示这些输入侧用量。若完全跳过 gather，主面板在无 breakdown 场景会缺分类，与 SMARK「用量可解释」目标冲突。

2. **主 total 与会话累计分口径**  
   - 主 UI 的 `totalTokens`：应等于**最近一个 step 的上下文窗口**（典型为 step.input + step.output，对应当前模型窗口占用直觉）。  
   - Footer / `details.usage.total`：应保持**会话累计**（所有 step-finish 之和），用于「本会话总共烧了多少」。  
   Source 测试明确断言两者不同，禁止用同一公式填两个展示位。

Original 路径在 `cli/cmd/tui/util/context-usage.ts` 与对应 test；tip 已迁到 `packages/tui`。
