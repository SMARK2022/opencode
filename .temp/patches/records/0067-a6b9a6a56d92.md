## 2. Source intent
In V1 TaskTool, when creating a child session:
```
const parentAgent = yield* agent.get(ctx.agent)
// permission: [...parentAgent.permission.filter(rule => rule.action !== "allow"), ...session filters]
```
Child task sessions must inherit parent agent non-allow rules (deny/ask/etc.) so subagents cannot silently widen past the delegating agent.
