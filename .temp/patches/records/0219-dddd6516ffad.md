## 3. SMARK Intent
- 用户可见行为：VS Code 扩展注册目录中有损坏/半写入 JSON 文件时，桥接发现跳过坏条目并仍选择活桥；非 UUID 格式的 JSON 文件、目录、新鲜损坏文件不被删除。
- 受保护不变量：清理路径只删除直接子文件且名为 UUID 清单，不删目录树或任意 JSON；缓存身份包含 registryDir 防止跨目录泄漏；原子写入确保崩溃不截断清单。
- 正常路径：发现 → 过滤 UUID 文件 → readEntry → PID 检查 → 健康检查 → 返回活桥列表。
- 边界路径：JSON 语法损坏 → CORRUPT_REGISTRY_ENTRY → 经宽限后清理；并发删除 → readFile catch → 跳过；非 UUID JSON → isRegistryManifestFile 排除。
- 并发/清理路径：writeRegistryFile 原子写入；removeRegistryFile 守护 UUID + isFile + 宽限期。
