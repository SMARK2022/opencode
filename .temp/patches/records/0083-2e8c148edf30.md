## 3. Source / SMARK #83 intent

Original restructures NetworkProxy around:

1. `nativeFetch` captured at module load (anti-recursion).
2. **Primary** `export async function fetch` — route then `directFetch`/`proxyFetch` via native.
3. **`fetchWithRoute` becomes passthrough** for custom auth adapters that must call `NetworkProxy.fetch` internally for the real hop.
4. Provider ternary: `customFetch ? fetchWithRoute(customFetch) : NetworkProxy.fetch`.
5. Call-site rewires to `NetworkProxy.fetch` + purpose tags.
6. `normalizeProxy` localhost → 127.0.0.1.
7. Original also **removes** multi-step recovery; three-way policy keeps recovery **inside** primary `fetch` (upstream strength) while adopting SMARK public API shape.
