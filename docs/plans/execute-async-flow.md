## 1. 目标与边界

让脚本用同一条执行路径完成工具发现、组合调用、结果过滤和必要的状态复用。实现负责调用帧、作用域、生命周期和输入合同，避免把这些内部问题交给 Agent 反复修复。

保留既有安全沙箱和宿主授权边界。没有引入原生 eval、第二套调度器、简单/复杂模式、失败后重试、自动工具改名、猜测主键、后台任务或额外构建配置。

生产代码相对共同基线的新增与删除合计不超过 1600 行，净增不超过 800 行；测试、文档单列。整个 PR 不超过 32 个文件。保持正常格式与关键测试，每个修改 hunk 有中文解释，合格中文注释与有效变更代码之比严格大于 15%。

## 2. 一条执行路径

```text
当前宿主工具与权限
  → 同源工具合同与发现目录
  → 新一轮 Execution + 可选保留的词法环境
  → 根作用域拥有的异步生产者
  → 唯一宿主调用边界的并发许可
  → 原工具校验、授权和执行
  → 业务结果、调用终态与宿主附件分别交付
  → 根作用域清理完成后释放环境租约
```

### 2.1 异步函数、组合器与闭包

- async 函数返回解释器的 Promise 值。每次函数调用有独立的参数、局部绑定和解释器帧，捕获的词法绑定按闭包规则共享。
- `await` 对普通值、已结算 Promise 同样让出执行。异步调用的异常在观察 Promise 时传播，而不是错误地同步抛出。
- `Promise.all` 并发观察成员，保持结果顺序，同时及时暴露后项失败。
- `Promise.allSettled` 保留输入顺序和普通失败数据；宿主中断仍是控制流，不能被前项等待挡住。
- `Promise.race` 只选择第一个结算结果，不取消生产者。败方在当前 Execute 内仍可继续等待；空数组保持 pending，直到执行结束或被中断。
- 生产者只归当前 Execute 根作用域所有。脚本返回、未捕获异常、超时或宿主中断均走同一清理入口；组合器不手动取消兄弟调用。
- 保留已有异步 `String.replace` 回调扩展，通过共同函数调用入口运行，不引入 `isReplaceCallback` 一类共享状态。

### 2.2 隐式异步迭代

`for await` 复用现有 Array、字符串、Map、Set 的可迭代域。每次取得下一项，包括空集合与终止项，都经过异步观察边界；Promise 项在绑定前结算，循环体保持顺序。break、return 和循环体异常的隐式退出也正确让出执行。Map 的键值对不做递归深层 await。

普通 `for-of` 保持同步。没有增加自定义异步迭代器协议、生成器或另一套事件循环。

### 2.3 并发、计时与清理

宿主工具调用和 fetch 共用 ToolRuntime 的八个许可。排队阶段不启动实际工具、校验、调用计数或 running 回执；取得许可后才进入原执行路径，因此叶子工具自己的 timeout 不计入排队耗时。没有新增通用 per-call timeout。

Execute 默认超时为 600000ms，可通过现有参数调整。实际脚本执行开始后，全局预算包含 ToolRuntime 许可队列等待和脚本运行；环境租约排队、隔离预跑及整段脚本审查在该计时范围之外。它与工具自身的计时职责分开。

`sleep(ms)` 使用当前根作用域下的 Effect 定时器，不占工具许可或调用预算。支持有限数值 `0 <= ms <= 2**31 - 1`；执行结束会清理尚未到期的等待。别名和跨单元保存的 sleep 仍归下一次当前执行所有，没有独立计时器服务。

## 3. 同源 Schema、目录和恢复信息

### 3.1 完整输入合同是唯一来源

Tool.make 保留完整 `inputContract`，再从它派生签名、搜索字段和输入简写形式。实际 Effect input 本身优先；JSON 描述的适配器可提供它持有的原始 decoder 合同；其余情况仍使用声明的 JSON Schema。

OpenCode 在原工具包装器捕获 `runtimeParameters`，与插件可修改的展示 schema 分开传递。适配器只提供元数据，不改变校验归属：原工具 decoder 仍负责校验、默认值和转换，且只执行一次。

这同时修复标量、单必填键对象及不支持简写的多必填键对象被错误展示 schema 覆盖的问题，避免只为标量添加特殊补丁。

### 3.2 确定性输入简写

在统一调用边界、原 decoder 之前归一化：

- 对实际对象合同，仅当恰好一个必填声明字段，或没有必填字段且只有一个声明字段，并且该字段是支持的标量域时，允许原始值包装到该字段。
- 对实际标量合同，允许只有一个自有可枚举字段且值域相符的对象拆包。
- 支持 string、number、boolean、null 及纯标量联合。显式 undefined、零参语义、数组、多字段对象、混合对象联合和不透明 schema 保持原合同。
- 不从 `path`、`query` 等名称猜主键，不通过失败后换一种参数形式重试。

归一化结果仍经过现有数据边界、原校验、工具 hook 和当前权限判断。纯展示 JSON Schema 不授予新输入形式。OpenCode 的原生宿主仍保持对象参数入口，不因库支持标量工具而放宽它。

### 3.3 单行签名与预算

Catalog、内联目录、search 和命名空间误调用建议共用同一个紧凑 TypeScript 签名。保留参数类型、可选性、联合、嵌套结构和真实返回类型；没有输出声明时显示 unknown。字段说明用于搜索索引，不再生成第二套多行 JSDoc 展示。

内联选择先考虑当前有效的原生 read、grep、glob、edit 路径，再按签名长度及完整路径稳定排序。全局 `search(...)` 是独立的同步发现入口，不虚构 `$opencode.search`。预算包含实际目录行和命名空间标题；零预算或超长核心签名仍可能不能内联，完整工具集合始终可搜索。

调用命名空间时，错误直接附带同一索引中的完整可用签名，并限制输出预算、说明省略数量。不会自动执行其中某个工具。

## 4. Notebook 式词法环境

传入已有 `environmentID` 可复用普通变量、函数、闭包及支持的解释器值；省略则创建新环境并返回标识。标识沿用宿主生成器并检查当前集合碰撞，不把短标识当权限凭证。

- 每个单元创建新的 Execution 和根作用域，重新绑定当前工具、权限、fetch、timeout 与日志。只保留词法状态，不复用在途任务或旧宿主上下文。
- 顶层名称可在后续单元重新声明；同一单元及函数局部的重复声明约束保留。失败前已发生的状态修改不会回滚。
- 同一环境通过租约串行到清理完成，不同环境可并行。取消排队者不会取消持有者。
- 环境只属于同一 Session 和 Location。当前存储位置检查与后续生命周期事件共同覆盖删除、移动、workspace 变化及实例关闭。
- 完成清理后，把可能保留的 Promise 从生产者 Fiber 转为安全终态，避免闭包保活旧执行上下文。

### 唯一保留策略

每个目录实例最多保留 64 个环境。容量不足时，只淘汰最早返回闲置的环境，使用现有 Map 顺序；活动和排队租约不可淘汰。最后一个租约退出才刷新闲置顺序，关闭条目只能删除，不能复活。

删除原有 30 分钟 TTL、每 owner 八个配额、时间戳、额外时钟和排序逻辑。单个 Session 可以使用全部 64 个槽位；没有时间到期承诺、堆字节配额或持久化保证。显式传入不存在、已淘汰或归属不符的标识会失败，不静默创建替代环境。

## 5. 结果、原文与准确回执

业务结果、日志、工具终态、强制上下文和附件各走原有交付渠道。脚本显式 return 优先，否则使用已有的最后值表达式语义；日志独立返回，不用 console 输出伪造成功结果。

未 await 的调用若失败或在根清理时中断，宿主必须如实显示其终态，不能只用父脚本的成功值描述整个工作。已经完成的副作用事实保留，不做隐式回滚或重试。

### 有限 MCP JSON 文本投影

仅对成功、无输出 schema、单个 text block 的 MCP 结果标记 JSON 文本候选；可同时保留独立媒体附件。structuredContent、有声明输出、多文本、资源及错误结果仍使用原投影，不递归猜测业务信封。

库只把独立 JSON 对象/数组转换为支持的普通数据。格式不符、原始标量或已知不能表示的结构保留准确原字符串；意外内部错误不吞掉。原生声明为字符串的工具结果不变，SDK 输出验证不被绕过。

原始文本存在弱引用来源映射中，不增加代理或自定义原型。String 和模板转换可读取原始文本；JSON.stringify 与最终数据出口仍反映业务数据。只在没有自有业务 text 字段时添加只读、不可枚举的原文别名；业务 text 始终优先。新的 spread/map 根值不继承旧根来源。
