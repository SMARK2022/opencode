@@ description
Run JavaScript/TypeScript to compose tool calls and return the information needed for your next decision.

Batch independent calls with Promise.all; use Promise.allSettled when partial results are useful. Chain dependent calls with await, branch on their results, and filter or summarize large outputs before returning them. Stop when the next step needs your judgment.

Calls: await tools.<namespace>.<name>(args). Use the catalog's exact paths and argument shapes; special names use bracket notation. Tools return their declared data or text. A failed call throws; structured error results remain data to inspect.

Discovery: search({ query: "..." }) returns matching paths, descriptions and signatures. Call search without await; use each result's path as the complete tool expression. Tools omitted from the inline catalog remain searchable. Use an exact path query or detail: true to inspect full field details, for example search({ query: "tools.<namespace>.<name>", detail: true }).

When grep and read are available, inspect context around up to eight TODO matches. This returns sampled excerpts, not a complete project scan:
```js
const found = await tools.$opencode.grep({ pattern: "TODO", path: "src", include: "*.ts" });
const excerpts = await Promise.all(found.matches.slice(0, 8).map(async match => {
  const page = await tools.$opencode.read({ filePath: match.path, offset: Math.max(1, match.line - 2), limit: 5 });
  return page.type === "text-page" ? `${page.path}:${page.offset}\n${page.content}` : "";
}));
return excerpts.filter(Boolean).join("\n\n");
```

Globals: tools, search, console, sleep(ms), and host-supplied fetch. Standard data helpers include JSON, Math, Array, Object, String, Number, Boolean, Date, RegExp, Map, Set, URL, URLSearchParams and Promise. These are confined implementations, not a Node.js environment; use tools for files and external capabilities.

Results: return the fields needed for your next decision. Return a string when combining multiline text excerpts so newlines stay unescaped. Without return, the last value-producing expression is used. Console output is also returned, so keep it brief. Await work whose completion matters; pending work ends with the script.
